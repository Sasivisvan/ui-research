# UI Components, Animations & Assets — Research

A builder's reference for making distinctive websites: 50 UI components, the animation toolkit, licence-checked assets, and foundations (tokens, responsive, performance, accessibility). Facts as of 5 Nov 2026.

## View it
- **Easiest:** download and open `Interface-Parts-Manual.html` in a browser. It's a single file (it needs internet for fonts and libraries).
- Or open `website/index.html`, keeping `content.js` next to it.

## Folders
- `docs/`: the Markdown docs. Start with `docs/README.md`, then `docs/00-start-here.md`.
- `reports/`: the master research report.
- `research_notes/`: the raw research notes, with sources.
- `website/`: site source. Run `node website/build.mjs` to rebuild after editing the docs.
