# Icons (2D/3D/vector/animated), Illustrations and Fonts for Websites: Curated Directory, Licensing and Implementation (as of Nov 2026)

Research date: 2026-11-05. Licenses were checked on official pages, official GitHub repos/LICENSE files, or the Iconify collections API (`https://api.iconify.design/collections`, which records each set's license SPDX, author and icon count). Live API pulls were also made from Google Fonts (`https://fonts.google.com/metadata/fonts`) and Fontshare (`https://api.fontshare.com/v2/fonts`). Where an official page blocked fetching (403/429/JS-only), that is stated and the claim is moved to Gaps or flagged as secondary-sourced.

Legend: Commercial = commercial use allowed; Attr = attribution legally required in the product (not just "appreciated").

---

## Key Question 1: Which resources are highest quality and genuinely license-safe for commercial websites?

### Takeaway
The safest, highest-quality choices are the permissive open-source UI icon sets: Lucide (ISC), Phosphor, Tabler, Heroicons, Iconoir, Radix, Bootstrap, Hugeicons-free, Akar, Eva, css.gg, Ionicons, Fluent (all MIT), and Material Symbols and Carbon (Apache-2.0). Simple Icons (CC0) covers brand logos. For illustrations, the CC0 sets are Open Peeps, Humaaans and Open Doodles, plus unDraw/ManyPixels/Blush/DrawKit, which use custom free licenses with no attribution. 3dicons is CC0 for 3D. For fonts, use SIL OFL families from Google Fonts, Fontsource or Bunny Fonts, plus Fontshare's ITF Free Font License. Watch for attribution traps: Font Awesome Free icons are CC BY 4.0, and so are Solar, the Streamline free sets, Basil, IconaMoon and Lets Icons. Flaticon, Storyset, Icons8 and Noun Project free tiers require credit, the Lordicon free tier requires credit, and Rive community files are CC BY. Several "free" sites have hard restrictions: Absurd Design's free license is non-commercial only, and Pangram Pangram fonts are personal-use trials only. Remix Icon changed its license in January 2026 to a custom "Remix Icon License v1.0" that forbids using icons as logos. unDraw and DrawKit forbid AI training.

### Cited Findings

#### 1A. Vector / UI icon sets (license-verified)

Counts in brackets are the Iconify collection totals at the time of the API pull (Nov 2026). These count every style or weight variant. Source for the license, author and count rows: [Iconify collections API](https://api.iconify.design/collections) unless another source is cited.

- **Lucide** (lucide.dev): about 2,020 icons in Iconify, plus Lucide Lab with 373. Stroke-based fork of Feather on a 24px grid. **ISC License**, with the copyright and permission notice required in copies. Some Feather-derived icons remain under **MIT** (© Cole Bemis), for example airplay, feather and x — [Lucide license](https://lucide.dev/license). Packages for React, Vue, Svelte, Solid, Angular and others. Icons are tree-shakable and "Only the icons you import are included in your final bundle", and each renders as an optimized inline SVG — [lucide-react docs](https://lucide.dev/guide/packages/lucide-react). Style note: clean and friendly. Because it is the default icon set of shadcn/ui it is now very common, close to the "default AI app" look (inference).
- **Phosphor** (phosphoricons.com): 6 weights (Thin, Light, Regular, Bold, Fill, Duotone). **MIT**. Packages: `@phosphor-icons/react` (tree-shaking), `@phosphor-icons/vue`, `@phosphor-icons/web` (webfont), Flutter, Elm, SwiftUI, Web Components, and Figma/Sketch/Penpot plugins — [Phosphor GitHub](https://github.com/phosphor-icons/homepage). Count conflict: the README says "1,248 icons and counting", while [Iconify](https://api.iconify.design/collections) lists 9,072 (v2.1.1), which is about 1,512 per weight × 6, so the README number is probably stale. Style: versatile. The duotone and thin weights give a more distinctive, editorial feel than Lucide.
- **Tabler Icons** (tabler.io/icons): 6,257 icons, 24×24 grid, 2px stroke, outline and filled. **MIT**, "Free for personal and commercial use". Formats: SVG, PNG, PDF, EPS, webfont, SVG sprite and a Figma plugin. Packages for React (`@tabler/icons-react`), Vue, Svelte, SolidJS, Preact, Angular, Astro and React Native. Paid add-ons: Bundle at $9 one-time and All Package at $69 — [Tabler Icons](https://tabler.io/icons). Iconify lists v3.50.0. Style: the largest coherent free stroke set, neutral and good for dashboards.
- **Heroicons** (heroicons.com, by Tailwind Labs): **MIT**. Styles: 24 outline, 24 solid, 20 solid (mini) and 16 solid (micro). Packages `@heroicons/react` and `@heroicons/vue` — [Heroicons GitHub](https://github.com/tailwindlabs/heroicons). Iconify lists 1,288 across all styles, v2.2.0, © Refactoring UI Inc. Style: very common in the Tailwind ecosystem. A small set.
- **Remix Icon** (remixicon.com): 3,200+ icons in Outlined (`-line`) and Filled (`-fill`) on a 24×24 grid. Packages `remixicon` (webfont/CDN), `@remixicon/react` and `@remixicon/vue`, a Figma plugin, and RemixIcon-MCP — [RemixIcon GitHub](https://github.com/Remix-Design/RemixIcon). **License change:** now the **"Remix Icon License v1.0" (January 2026)**. Free for personal and commercial use and attribution is optional. It **prohibits** standalone icon sales or packs, building competing icon libraries, and using icons "as a logo, trademark, brand identifier, or primary visual identity" even after light edits. Brand icons may only represent their brand — [Remix Icon License file](https://raw.githubusercontent.com/Remix-Design/RemixIcon/master/License). Conflict: [Iconify](https://api.iconify.design/collections) still lists Remix Icon as **Apache 2.0** (v4.8.0), which reflects the older license. Older releases (v4.8 and earlier) were Apache-2.0. Newer releases fall under the custom license.
- **Iconoir** (iconoir.com): 1,383 icons, 288 with solid variants, 1,671 SVGs in total, 24×24 grid. **MIT**. Packages: `iconoir`, `iconoir-react`, `iconoir-react-native`, `@iconoir/vue`, Flutter, Swift and CSS, plus a Framer integration and a Figma Community pack — [Iconoir GitHub](https://github.com/iconoir-icons/iconoir). Iconify lists v7.12.1. Style: light, slightly geometric, less ubiquitous than Lucide.
- **Radix Icons**: 332 icons on a 15×15 grid. **MIT**. Author is listed as WorkOS, v1.3.2 — [Iconify](https://api.iconify.design/collections). Style: crisp and small. Too limited to be a primary set for most sites.
- **Feather** (feathericons.com): 286 icons, **MIT**, © Cole Bemis — [Iconify](https://api.iconify.design/collections). Effectively superseded by Lucide, its maintained fork.
- **Bootstrap Icons** (icons.getbootstrap.com): "over 2,078 icons", v1.13.2. Use as SVG, SVG sprite or web font — [Bootstrap Icons](https://icons.getbootstrap.com/). **MIT** — [Iconify](https://api.iconify.design/collections). Style: utilitarian. Reads as "Bootstrap".
- **Material Symbols** (Google): **Apache License 2.0**, "attribution is appreciated but not required". These are variable fonts in Outlined, Rounded and Sharp, with axes opsz 20–48, wght 100–700, GRAD −50 to 200 and FILL 0–100. They can be loaded from Google Fonts (`fonts.googleapis.com/css2?family=Material+Symbols+Outlined`). The classic **Material Icons set is "no longer updated"** (no new icons since 2022). The Google-maintained npm package stopped at v3 (2016) — [google/material-design-icons](https://github.com/google/material-design-icons). Iconify lists 15,761 Material Symbols SVGs. Pictogrammers' community **Material Design Icons (mdi)** has 7,447 icons, Apache 2.0 — [Iconify](https://api.iconify.design/collections). Style: very recognizably Google/Android.
- **Font Awesome Free** (fontawesome.com), v7 (Iconify lists 7.3.1 with 2,000 solid, 272 regular and 608 brands): **icons are CC BY 4.0**, **fonts are SIL OFL 1.1** with the reserved font name "Font Awesome", and **code is MIT**. "MIT, SIL OFL, and CC BY all require attribution". The embedded attribution comments in the files satisfy this, so "do not actively work to remove them". Brand icons may only represent their brand — [Font Awesome LICENSE.txt](https://raw.githubusercontent.com/FortAwesome/Font-Awesome/7.x/LICENSE.txt). Style: dated and generic for modern product UIs. The free regular (outline) style has few icons. Pro is paid (pricing not verified).
- **Hugeicons** (hugeicons.com): Free has 6,000+ icons, Stroke Rounded style only. **Pro is $99/year** (60,000+ icons, 10 styles, 1 seat, 300K pageviews, 2GB bandwidth). **Pro Plus is $1,197 one-time** — [Hugeicons pricing](https://hugeicons.com/pricing). The free set (`hugeicons`, 6,065 icons) is **MIT** — [Iconify](https://api.iconify.design/collections). Note the Pro CDN usage is capped by pageviews and bandwidth.
- **Streamline** (streamlinehq.com): Pro has 300,000+ icons in 55 sets, 30,000 illustrations in 11 sets and 12,500 elements. Full access from $29/month, Icons from $19/month, Illustrations from $19/month. Limits of 100 icons or 50 illustrations per project. Integrations for Figma, Framer, VS Code, Webflow, plus an API and MCP — [Streamline pricing](https://home.streamlinehq.com/pricing). The **free sets on Iconify (Streamline 3,000; Plump free 1,499; Ultimate free 1,999) are CC BY 4.0**, so **attribution is required** — [Iconify](https://api.iconify.design/collections). Style: very high craft and many distinct aesthetics, a good way to avoid the generic look.
- **Central Icon System** (iconists.co/central): commercial and **license-key gated**. The npm packages (`@central-icons-react/*`) require a `CENTRAL_LICENSE_KEY`. Variants combine round or square corners, filled or outline, radius and stroke, for example `round-filled-radius-3-stroke-2` — [unpkg README](https://app.unpkg.com/@central-icons-react/square-filled-radius-0-stroke-1@1.0.1/files/README.md), [Raycast extension](https://www.raycast.com/tamino-martinius/central-icons). Price not verified.
- **Solar** (480 Design): Iconify lists 8,706 icons, and the official repo describes 6 styles (Linear, Line Duotone, Bold, Bold Duotone, Broken, Outline) — [Solar GitHub](https://github.com/480-Design/Solar-Icon-Set). License: **CC BY 4.0, so attribution is required** — [Iconify](https://api.iconify.design/collections). Third-party npm wrappers advertise MIT, GPL-3.0 or ISC. These do not change the upstream CC BY 4.0 — [search summary](https://community-en.eagle.cool/resource/solar-icons). Style: a polished duotone look that is popular on Dribbble.
- **Akar Icons**: 454 icons, **MIT**, v1.9.31. **Eva Icons** (Akveo): 490, **MIT**, v1.1.3. **css.gg**: 704, **MIT**, v2.1.4. **Ionicons** (Ionic): 1,357, **MIT**, v8.0.13. Source for all four: [Iconify](https://api.iconify.design/collections).
- **Fluent UI System Icons** (Microsoft): 19,945 icons (regular and filled, several sizes), **MIT**, v1.1.345 — [Iconify](https://api.iconify.design/collections). Style: Windows/Microsoft 365.
- **Carbon** (IBM): 2,638 icons, **Apache 2.0**, v11.91.0 — [Iconify](https://api.iconify.design/collections). Style: technical and enterprise. Pairs well with IBM Plex.
- **SF Symbols** (Apple): "Over 7,000 symbols, in nine weights and three scales". SF Symbols 7 was announced at WWDC25. The download requires macOS — [Apple SF Symbols](https://developer.apple.com/sf-symbols/). The page does not state usage terms on the web. See Gaps.
- **Other notable permissive sets** ([Iconify](https://api.iconify.design/collections)): MingCute 4,526 (Apache 2.0); Myna UI 2,620 (MIT); Material Line Icons by `line-md`, animated, 1,218 (MIT); Majesticons 760 (MIT); Pixelarticons 1,036 (MIT); IconPark 2,658 (Apache 2.0, ByteDance); Octicons 780 (MIT, GitHub); Famicons 1,342 (MIT); ProIcons 544 (MIT); System UIcons 430 (Unlicense); SVG Spinners 46 (MIT).
- **Attribution-required sets to be careful with** ([Iconify](https://api.iconify.design/collections)): Basil (CC BY 4.0), IconaMoon (CC BY 4.0), Lets Icons (CC BY 4.0), Pepicons (CC BY 4.0), Codicons (CC BY 4.0), Game Icons (CC BY 3.0), **OpenMoji (CC BY-SA 4.0, share-alike)**, Twemoji (CC BY 4.0), and Circum (MPL-2.0).

#### 1B. Aggregators

- **Iconify** (iconify.design / icon-sets.iconify.design / icones.js.org): the live API returned **276 icon sets and 473,655 icons**, each with its own license field — [Iconify collections API](https://api.iconify.design/collections). This is the best single place to check a set's license. The license is per set, not per Iconify.
- **unplugin-icons**: "Access thousands of icons as components on-demand universally". The README says about 150 sets and 200,000+ icons, which is stale compared with the API above. Works with Vite, Webpack, Rollup, esbuild, Rspack, Nuxt and Vue CLI. Frameworks: Vue 3, React, Preact, Solid, Svelte, Astro, Qwik, Ember and web components. Only imported icons are bundled. Supports auto-import, custom SVG loaders, and SSR/SSG with no flash of unstyled content. MIT, ESM-only, Node 20+ — [unplugin-icons GitHub](https://github.com/unplugin/unplugin-icons).
- **SVG Repo** (svgrepo.com): the license is per icon. The licensing page returned HTTP 429, so this was not verified. See Gaps.
- **Icons8** (icons8.com): free use, personal or commercial, requires a **link to Icons8** in the finished work. Free downloads are limited in size and format, and paid plans remove the link requirement — [Icons8 help (via search)](https://intercom.help/icons8-7fb7577e8170/en/articles/5136841-are-your-icons-free-for-commercial-use), [Icons8 community](https://community.icons8.com/t/free-license-attribution-requirements/1708). The license page itself returned 403. Style: many in-house styles. The 3D and "glass" styles look stock.
- **Flaticon** (Freepik): free use requires attribution, and Premium removes it — [Flaticon pricing page (via search)](https://www.flaticon.com/pricing/1312618). The legal page returned 403.
- **The Noun Project**: 10M icons and photos. Noun Pro costs $9.99/month or $3.33/month billed yearly, Team $6.67/month for 2 seats, EDU $1.67/month. Paid plans give "Royalty-free commercial licenses that never expire" and "Unlimited attribution-free icon downloads". Free accounts do not include royalty-free commercial licenses — [Noun Project pricing](https://thenounproject.com/pricing/). Free icons are CC BY, with some public domain — [Noun Project blog (via search)](https://blog.thenounproject.com/?p=9584). Quality is uneven because the library is contributor-made.
- **IconScout**: 14.4M+ assets (icons, illustrations, 3D, Lottie) — [IconScout pricing](https://iconscout.com/pricing). For free assets, "attribution is generally required", and Premium removes it. The license varies per asset — [IconScout free 3D page (via search)](https://iconscout.com/Free-3d-illustrations). The license page returned 403. Unicons, IconScout's open set, has 1,215 icons under Apache 2.0 — [Iconify](https://api.iconify.design/collections).

#### 1C. Brand and logo icons

- **Simple Icons** (simpleicons.org): "Over 3400 SVG icons for popular brands". Iconify lists 3,467, v16.36.0. **CC0-1.0** for the SVG paths, **but you must read DISCLAIMER.md**, because trademarks belong to the brands. Available via npm `simple-icons`, Packagist, jsDelivr/unpkg, cdn.simpleicons.org (with color options) and a font. Removed icons return 404 on `@latest` — [Simple Icons GitHub](https://github.com/simple-icons/simple-icons).
- **SVGL** (svgl.app): MIT-licensed project with a public API at svgl.app/api, light and dark variants and wordmarks, files limited to 21KB. Contributors must confirm they have the right to use each logo, and the project has no blanket trademark grant — [SVGL GitHub](https://github.com/pheralb/svgl). Style: color logos, popular for "trusted by" strips.
- **Devicon** (devicon.dev): icons for programming languages and dev tools, as a font or SVG. **MIT**, © 2015 Konpa. Product names and logos belong to their owners — [Devicon](https://devicon.dev/). Iconify lists 1,104 icons, plus 802 in Devicon Plain. **SVG Logos** by Gil Barbara: 2,064, CC0 — [Iconify](https://api.iconify.design/collections).
- General rule: the code or path license (CC0 or MIT) never grants trademark rights. Font Awesome and Remix Icon both say brand icons may only represent the brand itself — [Font Awesome LICENSE](https://raw.githubusercontent.com/FortAwesome/Font-Awesome/7.x/LICENSE.txt), [Remix Icon License](https://raw.githubusercontent.com/Remix-Design/RemixIcon/master/License).

#### 1D. 3D icons and 3D illustrations

- **3dicons** (3dicons.co, by Vijay Verma / @realvjy): "More than 1500+ hand made Open Source, Free & Premium 3d icons renders". The stats show 200 icons and 1,400+ renders. **CC0** ("without attribution"). Comes with a Figma file and plugin, and a Pro editor to change colors and angles — [3dicons](https://3dicons.co/). The source-file formats (Blend, GLB) were not confirmed on the page.
- **Thiings** (thiings.co, by Charlie Clark): "Free AI-Generated 3D Icons", 13,000+ — [Thiings](https://www.thiings.co/things). The license is **unclear and conflicting**. Secondary sources say commercial use is allowed with no attribution but resale or redistribution is not, and a full pack costs about $29. One listing claims CC0, which contradicts the resale restriction — [feedbagel](https://feedbagel.com/post/thiings-launches-free-collection-of-7000-ai-generated-3d-icons), [ProductCool](https://www.productcool.com/product/thiings-2). These icons are AI-generated, so check copyright and provenance.
- **Shapefest** (shapefest.com): "Over 100,000 3D renders" of abstract shapes. Personal and commercial use allowed. Editing and reselling as your own is not allowed. Free packs come at 512×512, and the 3000×3000 versions are paid. An Extended License covers UI kits. The site appears active (dated March 2026) — [Shapefest](https://www.shapefest.com/).
- **Microsoft Fluent Emoji**: **MIT**. Each emoji has **3D (PNG)**, Color (SVG), Flat (SVG) and High Contrast (SVG) folders. The repo has about 10.2k stars and was last pushed in August 2026 — [GitHub API/repo](https://github.com/microsoft/fluentui-emoji). Iconify lists Fluent Emoji (color) 3,126, Flat 3,145 and High Contrast 1,595, all MIT — [Iconify](https://api.iconify.design/collections). Style: friendly, glossy 3D. Very widely used on landing pages.
- **IconScout 3D**: a large 3D icon and illustration library. Free assets generally require attribution and Premium removes it. Licenses vary per asset — [IconScout 3D (via search)](https://iconscout.com/Free-3d-illustrations).
- **Spline** (spline.design): Free $0 (watermark on web exports). Hobby $15/seat/month (no watermark on 3D web exports). Pro $30/seat/month (Code Export, USDZ/STL, glTF with textures, Apple/Android exports). Max $70. Enterprise adds self-hosted export — [Spline pricing](https://spline.design/pricing). The community file remix license was not stated on the pricing page.
- **Vectary** (vectary.com): Free plan with 5 projects and 1 seat. Starter $25/month. Team and Business tiers. When a subscription is canceled, **the workspace locks and public links and embeds stop working** — [Vectary pricing](https://www.vectary.com/pricing/). This is a lock-in risk for embedded 3D on a production site.
- **Blush** (blush.design): includes 3D collections among its illustration sets. License terms are under Illustrations (1E).

#### 1E. Animated icons

- **LottieFiles**: free animations use the **"Lottie Simple License (FL 9.13.21)"** © Design Barn Inc. **Commercial use is allowed and attribution is not required.** You may not compile files into a similar or competing service or impose additional terms — [LottieFiles license](https://lottiefiles.com/page/license). Quality varies a lot by creator.
- **Lordicon** (lordicon.com): 49,000+ icons. On the **free plan attribution is required** ("credit needed") and commercial use is allowed. PRO needs no attribution and is time-limited. The Embed HTML/CDN option is capped at 1M requests per month. Lottie JSON and static formats are also available — [Lordicon licenses](https://lordicon.com/licenses). Style: polished, but highly recognizable "Lordicon motion".
- **useAnimations** (useanimations.com): about 300 micro-animations in Lottie JSON plus static SVG, with the `react-useanimations` package and shadcn CLI support. **MIT, commercial use allowed, attribution optional.** Interaction modes: loop, click-toggle, hover and others — [useAnimations](https://useanimations.com/).
- **lucide-animated** (lucide-animated.com, repo pqoqubbw/icons): animated Lucide-style icons, **MIT**, about 8.3k GitHub stars. Ships a `registry.json`, which suggests the shadcn registry install method — [GitHub](https://github.com/pqoqubbw/icons).
- **itshover** (itshover.com): 186+ hover-animated React icons built with React and Motion (motion/react). **MIT**. Install via the shadcn CLI or by copying components. No official releases yet, so pin a commit — [GitHub](https://github.com/Nani-LM10/itshover), [BrightCoding review](https://blog.brightcoding.dev/2026/05/04/itshover-the-animated-icon-library-every-react-developer-needs).
- **Rive community / Marketplace** (rive.app): "Marketplace files are all shared under a **CC BY** license", so **attribution is required**. Files can be remixed into your own account — [Rive docs: marketplace overview](https://www.rive.app/docs/community/marketplace-overview), [community overview](https://rive.app/docs/community/community-overview).
- **Material Line Icons (`line-md`)**: 1,218 SMIL/CSS-animated SVG icons, **MIT** — [Iconify](https://api.iconify.design/collections). These are animated SVGs that need no JavaScript runtime.

#### 1F. Illustrations

- **unDraw** (undraw.co): free, including commercially, with **no attribution**. **Prohibited:** compiling assets into a competing service, redistributing in packs, scraping or automated downloads without consent, and using assets to "train, fine-tune, validate, or test AI or ML models" — [unDraw license](https://undraw.co/license). Style: flat, single accent color. This is the archetype of the overused SaaS look. Wikipedia names unDraw among the stock sources that spread Corporate Memphis — [Wikipedia: Corporate Memphis](https://en.wikipedia.org/wiki/Corporate_Memphis).
- **Open Peeps** (openpeeps.com, Pablo Stanley): **CC0**, "over 584,688 possible combinations", PNG and SVG, works in Sketch, Figma, XD, Studio and Blush — [Open Peeps](https://www.openpeeps.com/). Style: hand-drawn black-line characters. Warmer than flat vector, but also widely used.
- **Humaaans** (humaaans.com, Pablo Stanley): **CC0**, "Free for commercial or personal use". Built for Sketch, Studio and Blush — [Humaaans](https://www.humaaans.com/). Style: mix-and-match flat people. The style is close to Corporate Memphis.
- **Open Doodles** (opendoodles.com, Pablo Stanley): **CC0**, "No need to credit". SVG and PNG, with some GIFs — [Open Doodles](https://www.opendoodles.com/).
- **Blush** (blush.design): "All Illustrations published on Blush can be used for free". **No attribution** required and commercial use is allowed. **No** resale or redistribution, no merchandise, no compiling into a competing service, and no ownership claims — [Blush license](https://blush.design/license). Style: many artist collections, so you can pick distinctive non-generic artists. Paid plans exist (pricing page not fetched).
- **DrawKit** (drawkit.com, now associated with designstripe): "Attribution is not required". Commercial use is allowed. **Prohibited:** redistribution, stock and template sites, merchandise, and **AI/ML training** — [DrawKit license](https://www.drawkit.com/license).
- **Storyset** (storyset.com, Freepik): **attribution required** for free use. Removing it requires a Flaticon Premium subscription. No resale or stock use, and no use in logos unless substantially modified. Includes an online animate and customize tool — [Storyset terms](https://storyset.com/terms). Style: Freepik stock, very common.
- **ManyPixels Gallery** (manypixels.co/gallery): free for commercial use with **no credit**. No competing service and no packs. Styles: Playstroke, Birdview, Chromablue, Colossalflat and Azureline. SVG — [ManyPixels](https://www.manypixels.co/gallery).
- **IRA Design** (iradesign.io, Creative Tim): components "can be downloaded for free under **MIT License**", for commercial or personal use. 200+ components and five gradient options. AI, SVG and PNG — [IRA Design](https://iradesign.io/). Style: gradient flat characters, somewhat dated (around 2019).
- **Absurd Design** (absurd.design): **the free license is NON-COMMERCIAL ONLY.** It requires the exact credit "Illustration(s) from absurd.design" with a link. No client or commercial work, no templates or themes, no AI training. Commercial use needs the paid membership license — [Absurd free license](https://absurd.design/freelicense). Style: surreal hand-drawn, "free from AI". Distinctive, but on the free tier it is **not safe for commercial sites**.
- **illlustrations.co** (Vijay Verma / Overlayz): 120+ open-source illustrations in SVG, PNG and Figma, plus a Figma plugin. Freemium sets include Long Heads and Croods — [illlustrations.co](https://illlustrations.co/). The license page was not fetched (see Gaps).
- **Lukasz Adam** (lukaszadam.com/illustrations): states "No attribution required" and "commercial and personal use". Lists "CC0 license (MIT license)", which is ambiguous. SVG, PNG and WebP. The ZIP download requires an email — [Lukasz Adam](https://lukaszadam.com/illustrations).
- **Streamline Illustrations**: 30,000 illustrations in 11 sets, from $19/month — [Streamline pricing](https://home.streamlinehq.com/pricing).
- **Tabler Illustrations**: included in the paid "All Package" ($69) — [Tabler](https://tabler.io/icons).
- **Status flags (Nov 2026):** **Stubborn** (stubborn.fun) returned connection refused, so it may be dead. **Popsy** (popsy.co) now redirects to app.popsy.co/dashboard, which returned HTTP 530, so it may be defunct or pivoted. **Delesign** free graphics redirect loops (http/https), so it was not verified. See Gaps.

#### 1G. Fonts: sources and licenses

- **Google Fonts**: the live metadata endpoint returned **1,959 families, 565 with variable axes**. It also records popularity ranks, for example Roboto #2, Open Sans #3, Inter #5, Montserrat #7, Poppins #8 and Lato #9 — [Google Fonts metadata](https://fonts.google.com/metadata/fonts). The fonts are open source (mostly SIL OFL) and free for commercial use — [Typewolf free fonts](https://www.typewolf.com/free-fonts).
- **Fontshare** (fontshare.com, Indian Type Foundry): the API returned **100 families**. Most carry `license_type: itf_ffl` (ITF Free Font License), for example Satoshi, General Sans, Clash Display, Clash Grotesk, Cabinet Grotesk, Switzer, Supreme, Zodiak, Gambetta, Erode, Sentient, Boska, Bespoke Serif, Ranade, Chillax, Panchang, Tanker and Melodrama. #### 1H. Corporate Memphis context (for avoiding it)

- Corporate Memphis ("Alegria") is a flat style with "long, elastic arms, small heads", odd skin colors (purple or blue) and stock scenes like high-fiving and watering plants. It was created by Buck for Facebook in 2017 and copied by Slack, Google and others. Stock sites, **including unDraw**, spread it. *Creative Bloq* said that by 2023 its popularity had fallen due to "uninspired design" and oversaturation. *Fast Company* (2022) reported a return toward 3D and skeuomorphism — [Wikipedia: Corporate Memphis](https://en.wikipedia.org/wiki/Corporate_Memphis).

### Inferences
- **Tier list for commercial safety (no-credit, permissive):** Lucide, Tabler, Phosphor, Heroicons, Iconoir, Hugeicons-free, Bootstrap, Fluent, Material Symbols, Carbon, MingCute, Simple Icons, 3dicons, Fluent Emoji 3D, Open Peeps, Humaaans, Open Doodles, useAnimations, lucide-animated, itshover, Google Fonts (OFL), Fontshare. Next come the "free, no credit, but custom license with restrictions" options: unDraw, DrawKit, Blush, ManyPixels, LottieFiles (Lottie Simple License) and Remix Icon v1.0. Last come the "credit required" options: Font Awesome Free icons, Solar, the Streamline free sets, Flaticon, Storyset, Icons8, Noun Project free, IconScout free, Lordicon free and Rive community. Avoid entirely for commercial work: Absurd free, Pangram trials and Thiings (license unclear).
- With CC BY sets (Solar, Streamline free, Font Awesome icons), a credits page or an HTML/SVG comment probably satisfies the license, but legal teams often prefer to avoid CC BY in white-label or client products.
- If you use an AI design or coding workflow, note that unDraw, DrawKit and Absurd explicitly ban AI training. Using the assets in a site is fine, but feeding them into a model is not.
- For distinctiveness: Lucide and Heroicons now act as visual defaults for shadcn and Tailwind. The quickest ways to look less generic are Phosphor at a non-regular weight (thin, duotone), Iconoir, a premium Streamline or Central set, or a custom-tuned stroke width.

## Key Question 2: Which free typefaces do designers recommend to avoid the generic "AI slop" look in 2025–2026, and what pairings work?

### Takeaway
Inter, Roboto, Open Sans, Montserrat, Poppins and Lato are measurably the most-used Google Fonts (popularity ranks 2–9). Community "AI slop" guides list Inter, Roboto and Arial as tell-tale defaults. The usual advice is a characterful display face (a serif or an expressive grotesk) paired with a quieter text face. Even the 2024–25 "escape" picks (Instrument Serif, Bricolage Grotesque, Geist, Space Grotesk) are now top-100 on Google Fonts. Genuinely less-saturated free options are Fontshare's ITF families, Collletttivo/League/Uncut faces, and newer or lower-ranked Google families such as Young Serif, Gloock, Newsreader, Familjen Grotesk, Schibsted, Funnel Display, Host Grotesk, Martian Mono, Fragment Mono, Bodoni Moda, Kalnia, Big Shoulders, Anybody, Recursive, Science Gothic and Zalando Sans Expanded.

### Inferences
These pairings are the researcher's suggestions, built from the license-verified families above. Every font listed is free for commercial web use (OFL or ITF FFL).
- **Editorial / magazine:** Newsreader (opsz) or Young Serif headlines, with Source Serif 4 or Literata body and Familjen Grotesk UI. Alternatives: Zodiak or Gambetta (Fontshare) with Switzer. Fraunces with SOFT/WONK axes tuned away from the defaults, plus Hanken Grotesk.
- **Brutalist / raw:** Big Shoulders or Anybody (wide/condensed widths) or Collletttivo's Sinistre/Ronzino, with Martian Mono or Fragment Mono body and labels. Alternatives: Space Mono everywhere, or Tanker/Panchang (Fontshare) with JetBrains Mono.
- **Tech / developer:** Geist plus Geist Mono is now common, so prefer Mona Sans/Hubot Sans (wdth axis) or Host Grotesk with Martian Mono or Recursive. Alternatives: Science Gothic (width and contrast axes) with Azeret Mono. Supreme or General Sans with JetBrains Mono.
- **Luxury / fashion:** Bodoni Moda (opsz) or Gloock headlines, small-caps tracking, and Switzer or Schibsted Grotesk body. Alternatives: Boska or Gambarino (Fontshare) with Satoshi. Kalnia (wdth) display with Libertinus Serif text.
- **Playful / consumer:** Bricolage Grotesque (opsz/wdth) or Clash Display with Satoshi or Onest. Alternatives: Gabarito or Funnel Display with Rethink Sans. Caprasimo or Chillax for headlines.
- Practical rule: keep at most two families plus an optional mono. Use variable axes (opsz, wdth, SOFT/WONK, CASL) to get character from one file. Rank on Google Fonts (above about 150) is a usable proxy for "not overused".

## Key Question 3: How should icons (and fonts) be implemented efficiently on the web for desktop and mobile?

### Takeaway
For most apps the default should be a tree-shakable icon component library with named imports (Lucide, Tabler, Phosphor), or Iconify through unplugin-icons, which compiles only the icons you use into components and supports SSR with no flash of unstyled content. Avoid `Icons[name]` namespace lookups and barrel re-exports, which defeat tree-shaking. Use an external SVG sprite with `<use href>` for icon-dense pages or very large static sets, so path data stays out of the JS bundle and gets HTTP-cached. Avoid icon fonts: web.dev recommends SVG over them. For fonts: use WOFF2 only, subset with unicode-range, put @font-face inline in the head, preload only critical files, choose font-display per role (`optional` for body, `swap` for brand), and remove fallback layout shift with metric overrides (Fontaine, Capsize, size-adjust).

### Cited Findings
**Icons**
- Tabler's guide recommends a maintained, typed, tree-shakable component library as the default. Use inline JSX only for a few bespoke icons, SVGR for custom design-file icons, and sprites with `<use>` "for pages with thousands of icon instances". Sprite drawbacks: string IDs "fail silently" on typos and a build step is needed. Performance tips: named imports, **avoid `Icons[iconName]` dynamic lookups** (they keep every icon in the bundle; build an explicit map instead), avoid barrel re-exports, and consider sprites alongside a component library on icon-dense screens — [Tabler: How to use SVG icons in React](https://tabler.io/guides/how-to-use-svg-icons-in-react).
- Accessibility: decorative icons next to text get `aria-hidden="true"`. Icon-only buttons need `aria-label` on the **button**, with the SVG hidden — [Tabler guide](https://tabler.io/guides/how-to-use-svg-icons-in-react).
- Practitioner comparisons say inline SVG components inflate the JS bundle and the DOM, while sprites keep path data out of JS and are cacheable. A "fat sprite" can slow first load, so split it. Lazy-load rarely used icons. **No rigorous public benchmark was found** — [DEV: SVG icon management comparison](https://dev.to/simprl/a-comprehensive-comparison-of-svg-icon-management-options-in-react-js-projects-glc), [DEV: SVG sprites](https://dev.to/gouranga-das-khulna/use-svg-sprites-to-make-your-react-app-load-faster-319a).
- unplugin-icons: `~icons/{collection}/{icon}` imports, on-demand bundling, auto-import for Vue/React/Solid, a `?raw` SVG string export, and custom local SVG collections with HMR. SSR/SSG output avoids flash of unstyled content — [unplugin-icons](https://github.com/unplugin/unplugin-icons).
- Lucide React: per-icon tree-shaking and inline SVG output, with size, color and strokeWidth props — [lucide-react](https://lucide.dev/guide/packages/lucide-react).
- Icon fonts: web.dev advises "Replace them with SVGs where possible", because fallback icon fonts can render as the wrong glyph and change meaning — [web.dev font best practices](https://web.dev/articles/font-best-practices). Material Symbols is a notable exception: a variable icon font with FILL, wght, GRAD and opsz axes, best served from Google Fonts — [google/material-design-icons](https://github.com/google/material-design-icons).
- Animated icons: useAnimations ships Lottie JSON plus **static SVG fallbacks** "useful where nothing should move" — [useAnimations](https://useanimations.com/). `line-md` animated SVGs need no runtime — [Iconify](https://api.iconify.design/collections). Lordicon's CDN embed is capped at 1M requests per month — [Lordicon licenses](https://lordicon.com/licenses).
- Brand icons via CDN: cdn.simpleicons.org serves colorized SVGs. `@latest` URLs can 404 when an icon is removed, so pin versions — [Simple Icons](https://github.com/simple-icons/simple-icons).

**Fonts**
- web.dev recommendations:
  - Put `@font-face` and critical CSS inline in `<head>`, but don't inline the font files.
  - Preconnect to third-party font origins, with `crossorigin`.
  - Preload sparingly. Preload ignores unicode-range and takes bandwidth from other resources.
  - "Use only WOFF2 and forget about everything else". It is about 30% smaller than WOFF thanks to Brotli.
  - Subset and use `unicode-range`, with tools such as subfont and glyphhanger. Check that the license allows subsetting.
  - Self-hosting "isn't automatically faster", so test it.
  - Variable fonts consolidate weights, but one variable file can be larger than one static font.
  - Consider `system-ui`.
  - font-display values: `block` (about 2–3s block), `swap` (0ms block, infinite swap), `fallback` (100ms block, 3s swap), `optional` (100ms block, no swap). Use `optional` for performance and no shifts, `swap` for branding. Use `size-adjust` to reduce CLS.
  — [web.dev](https://web.dev/articles/font-best-practices)
- **Fontaine** (UnJS, MIT): generates fallback `@font-face` rules with `size-adjust`, `ascent-override`, `descent-override` and `line-gap-override`. Plugins for Vite, webpack and Next.js, with examples for Astro, Gatsby and Docusaurus. A PostCSS route exists for Sass. Nuxt uses `nuxt-font-metrics`. The playground showed **CLS dropping from 0.24 to 0.054** — [Fontaine](https://github.com/unjs/fontaine).
- **Capsize**: sizes text by cap height and trims the space above caps and below the baseline (`@capsizecss/core` `createStyleObject`, with per-font metrics packages such as `@capsizecss/metrics/roboto`) — [Capsize](https://seek-oss.github.io/capsize/).
- Fontsource npm self-hosting gives version pinning, offline/PWA support and privacy — [Fontsource](https://fontsource.org/docs/getting-started/introduction). Bunny Fonts works as a drop-in, privacy-friendly CDN replacement for Google Fonts CSS v1 — [Bunny Fonts](https://fonts.bunny.net/about).

### Inferences
- **Recommended icon stack:** (1) Use one primary set with consistent stroke width and grid, for example Lucide/Tabler/Phosphor via the package or `unplugin-icons`. (2) Keep a typed icon map, `const icons = { search: SearchIcon, ... }`, for data-driven icons. (3) For lists or tables with hundreds of icons, render `<svg><use href="/sprite.svg#id"/></svg>` from a build-generated sprite, which avoids hydration and DOM cost on mobile. (4) Gate animated icons behind `prefers-reduced-motion` and lazy-load Lottie and Rive players (the Lottie and Rive runtimes are heavy compared with SVG; sizes not verified here). (5) Use `currentColor` so icons follow theme and dark mode.
- **Recommended font stack for mobile:** at most 2 variable WOFF2 files, Latin-subset. Use `font-display: optional` for body (or `swap` plus Fontaine fallback metrics), preload only the LCP headline font, and use `next/font` or Fontaine-style overrides to keep CLS near zero.

### Gaps
- No controlled benchmark comparing bundle size and runtime cost of inline components, sprites and icon fonts was found.
- The runtime sizes of lottie-web, dotLottie and the Rive web runtime were not retrieved.
- Iconify's web component and API docs returned connection resets. Its on-demand CDN rendering trade-offs (requests at runtime versus build-time bundling) are not sourced here.
